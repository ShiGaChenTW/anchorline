Agent 如何互動

SpecForge 把 Agent 當「可登入的角色」：有編輯／核准權限、可被指派簽核，也可在 Agent 管理頁調整 prompt 與進場作業。

  • 人員 vs Agent：人員負責真實決策；Agent 可撰寫或簽核，但同一 Agent 族系不可既寫又核。
  • 進場作業：在「Agent 管理」選 Agent → 指定專案與任務（編輯／覆核／核准）→ 佇列執行。
  • 簽核鏈：管理中心可設定工程／設計／資安／法務關卡與預設指派。
  • 密碼：Agent 也有登入密碼；安裝入門包時會沿用你剛設的管理員密碼，之後可在管理中心改。

可略過；之後仍可在 Agent 管理或管理中心新增。
