Plannotator → Anchorline：路線 A 規劃與擬真效果

不重做批註 UI。本機繼續用 plannotator 審當下；Anchorline 最多加一條薄橋：探測 CLI、一鍵開啟 PRD／plan、可選把決策寫進稽核——且永不自動簽核。 本頁上半是規劃口徑，下半是可點的擬真效果（非產品實作）。

範圍（做／不做）

做

  • [ ]設定頁探測 plannotator（比照 openspec／gh：指定路徑 → PATH → 常見安裝點）
  • [ ]review／tracking：「用 Plannotator 開啟」→ annotate <path> --gate --json
  • [ ]可選：JSON 決策寫成稽核一筆（路徑 + decision + 摘要）

不做

  • 不重做 annotate／code review UI
  • 不 hook ExitPlanMode、不 spawn coding agent（D7）
  • 不讓 Plannotator Approve 觸發 approveAndLock
  • 不做 PR diff 檢視器（SCOPE 禁令）

實作步驟（重開時）

  1. 探測模組 — 純函式 + 測試（仿 openspec 探測形狀）
  2. 設定 UI — 路徑欄、狀態 pill、找不到時安裝提示（不崩潰）
  3. 開啟動作 — 原生端只跑白名單子指令；回傳 JSON／exit
  4. 稽核映射（可選） — plannotator.decision 事件；明確標「非簽核」
  5. UAT — 找到／找不到／Approve／Annotated／Dismissed 五題
