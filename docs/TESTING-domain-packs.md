## 修正紀錄

### 第一輪回報 → 已修

| 回報 | 根因 | 處置 |
|---|---|---|
| 設定頁「選擇領域包資料夾」按不動 | 設定頁在 iframe 裡，Tauri 只把原生通道注入頂層 frame | iframe 同源向父層借用 internals |

### 第二輪回報 → 已修

| 回報 | 根因 | 處置 |
|---|---|---|
| 寫作教練文字太多會卡住拉不動 | `.coach-body` 是直向 flex，子項預設被**壓縮**而非溢出 → `scrollHeight` 永遠等於 `clientHeight` → 捲軸從不出現 | `flex: 0 0 auto`。量到 644 → 1403，滾輪實際捲 600px |
