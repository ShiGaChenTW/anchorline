# UAT: 跨專案 UAT 進度三個曝光面

**建立時間：** 2026-08-15 12:47
**最後更新：** 2026-08-15 12:47
**狀態：** 進行中

> **目的：**驗收「所有專案加起來還有幾題沒勾」這個數字在三個地方的**畫面**——總覽、專案儀表板、開啟 App 的歡迎畫面。程式閘門（tsc／1214 例單元測試／cargo check／vite build）全綠，但 Interceptor 擴充功能卡著，agent 對版面**一個字都沒有證據**。
>
> **測試編號：**UAT-20260815-03
>
> **前置（一次就好）：**
> 1. 這一版已由 agent 執行 `bun run app:install` 重建安裝完成，直接開 App 即可
> 2. 如果 App 已經開著，先完全結束再重開（歡迎畫面一次啟動只跳一次）
>
> **三個詞的口徑（判題時會用到）：**
> - **沒勾** ＝ 還沒判過的題
> - **待修** ＝ 判完是失敗、等著修的題
> - **暫時跳過** ＝ 按過「本輪收工」被批次跳過的題
>
> 三者互斥，同一題只會算進其中一邊。
>
> **已通過免測：**`tsc` 綠、`bun test` 1214 例綠（基準 1191，+23）、`cargo check` 綠、`vite build` 綠。逐份報告列表（每份一列、進度條、專案名 chip）是先前已出貨的功能，這次一行未動，不在本清單範圍。
>
> **注意：**第 9 題要改動報告的勾選狀態，請放在最後做。

> 在 Anchorline 的 Task Tracking 開這一份逐題勾選。「失敗」與「不測」必須填說明。

## T1 歡迎畫面出現實測進度 <!-- anc:t=S1BGYVJ3 -->

**流程：**
1. 完全結束 Anchorline（⌘Q）
2. 重新開啟 Anchorline
3. 看歡迎畫面上「專案數／草稿數」那兩個數字方塊的下方

**預期：**
出現一行文字，開頭是「全部專案實測」，接著是「還有 N 題沒勾」，最右邊有「看逐份 ›」。整行只有一行，沒有列表、沒有進度條、沒有百分比

## T5 總覽合計的數字是對的 <!-- anc:t=8Q74CX6A -->

**流程：**
1. 在總覽頁看合計那行的「還有 N 題沒勾」
2. 把下方逐份列表每一列的「X/Y 已結」抄下來
3. 每一列算 Y 減 X，全部加起來
4. 跟合計的 N 比對

**預期：**
兩個數字相同。這一題是整個功能唯一能證明數字正確的驗證，比版面重要

**結果：** 未測

## T9 暫時跳過的題不會憑空消失 <!-- anc:t=NV1AKGWF -->

**流程：**
1. 隨便開一份還有未測題的實測報告
2. 記下目前總覽合計的「還有 N 題沒勾」是多少
3. 在該報告按「本輪收工」，再按一次確認
4. 回到總覽頁（如果沒自動更新就重新整理該頁）
5. 看合計那一行

**預期：**
「還有 N 題沒勾」變少了，但同一行出現「另有 M 題暫時跳過」，M 大約等於剛才被跳過的題數。跳過的題數不會憑空不見
