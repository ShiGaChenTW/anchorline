## 這輪學到、值得帶走的三件事

1. **要求 agent 邊做邊把結論寫進 repo 內的檔案，這輪四個 agent 全部在交付後直接斷線**，
   其中兩個一句回報都沒有 —— 工作沒掉的唯一原因就是這條規矩。
   但它有邊界：**檔案保得住已完成的工作，保不住未執行的指令**（有一次指令完全沒被執行，
   是我回頭 grep 檔案才發現）。所以每一則指派都要回頭查檔案，不看回話。
2. **source-grep 型測試的解析度到「函式」為止。** 它擋得住 Wave 1 的 F0（新參數只有測試在傳），
   但 C-1/C-3 兩條缺陷都在**函式之間**，測試全綠。要抓那種形狀得抽出純函式餵時序替身。
3. **文案與行為對不上，不管往哪個方向錯都是同一個缺陷。** 這輪犯了兩次（先是鈕說會破壞
   而其實 no-op，後來行為改了文案還說不生效）。最後的解法是雙向合約測試：
   先跑 store 證明行為做到了，才允許斷言文案講那句話。
